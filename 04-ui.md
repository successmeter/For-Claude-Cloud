# 4. UI

## 4.1 Foundation

- React SPA built on the **Mosaic React** template (Tailwind, Chart.js, React Router, flatpickr, Google Places
  autocomplete). Unused template pages are removed. The Mosaic Sidebar and Header become the app shell.
- New dependency: **TanStack Query** (API caching). Charts reuse existing Chart.js components.
- Auth is a first-party **Sanctum httpOnly cookie session**; the browser stores no tokens. OIDC is for the other tools.
- AUD formatting, venue-local time zones, role-based route guards (viewers cannot see Data sources or the audit log).
- **Suppression is server-side only.** The API returns an *unavailable* state below threshold and the UI
  renders it. The UI never receives or displays counts below the threshold.

## 4.2 Navigation

Header: org and venue switcher. Sidebar: Overview, Benchmarks, Strategy, Data sources, Competitor sets, Settings.

## 4.3 Screens

| Screen | Content |
|---|---|
| **Onboarding** | Org -> venue (Places autocomplete resolves market and region) -> segment and cuisine -> connect data (Square OAuth, CSV upload or intermediary) -> contribution consent -> competitor set (import an existing Web set or create). |
| **Overview** | Yesterday's revenue; 7- and 28-day totals; same-weekday WoW and YoY; daily revenue chart; flagged anomalies; data-freshness badge. |
| **Benchmarks** | Filter bar: Market, Segment, Cuisine (geography defaults to region). Tabs: **Cohort** and **Competitor set**. Day / week / month toggle. Chart of the venue's indexed growth against the cohort average. Available views say "based on 5+ venues". |
| **Strategy** | Plan list with a Revenue or Web source badge. Plan detail: summary, supporting findings (linked to the charts), prioritised actions with impact and effort. "Generate" shows remaining AI budget. "Send to Execution" is present but disabled until that tool exists. |
| **Data sources** | Connections with health, last sync and backfill progress; upload wizard (template, mapping, preview, commit). |
| **Competitor sets** | Members editor; Revenue / Web visibility toggle; composition-lock notice. Never shows which members are subscribers. |
| **Settings** | Users and roles, consent, AI usage and budget, and audit log view for owners. |

## 4.4 Unavailable and empty states

Most benchmark views will be unavailable at launch. The empty state is part of the product:

- "Not enough participants for this selection. Try a broader selection." with no counts.
- Own-history value (trends, anomalies, strategy from own data) is always shown so the tool is useful on day one.
- Competitor-set view is expected to be unavailable for most subscribers early (it needs 5 distinct matched subscribers).
